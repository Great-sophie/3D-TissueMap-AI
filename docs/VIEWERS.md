# Interactive 3D viewers

The two HTML viewers originate from `runs/3d_tissue_microenvironment_viewer_v1/`. They are copied to `docs/viewers/` for GitHub Pages. They contain research visualization data and must be reviewed for public redistribution before pushing.

- [ROI voxel viewer](https://great-sophie.github.io/3D-TissueMap-AI/viewers/roi_voxel_viewer.html)
- [Centroid marker viewer](https://great-sophie.github.io/3D-TissueMap-AI/viewers/centroid_marker_viewer.html)
- [Viewer landing page](https://great-sophie.github.io/3D-TissueMap-AI/viewers/index.html)

For a local preview, run `python -m http.server 8000 --directory docs` from the GitHub export root, then open `http://localhost:8000/viewers/`.
